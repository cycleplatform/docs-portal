# Container Logs

Each container on Cycle has a dedicated log query page.  This page helps users to parse logs in a much more sane and approachable way. 

This page shows the following information:


| **Field**   | **Description**                                                                 |
|-------------|---------------------------------------------------------------------------------|
| **Time**    | The timestamp indicating when the log entry was recorded.                       |
| **Instance**| The specific instance that generated the log entry. |
| **Message** | The content of the log entry. |


![Container Logs](https://static.cycle.io/portal-docs/containers/log-no-search.png)

The image above shows an empty query which will return the most recent logs to the screen.  For users that want to identify a more specific subset of the available logs, enter a query. 

![Container  Logs plus Search](https://static.cycle.io/portal-docs/containers/log-search.png)

Users who enter a query term will get a return of all logs that include the query term.
